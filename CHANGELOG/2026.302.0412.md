# 2026.302.0412 — fix(docs-site): the pin report names its state, and the skill body proves it

## Summary

The skill body said "reports one of three states" directly above a FOUR-row table, and the script
reported four: `current`, `BEHIND`, `DISAGREE`, `UNJUDGEABLE`. The count was wrong and nothing
caught it — the self-test proved each branch discriminated, but never compared the code's list
against the prose's.

A second defect sat on the same surface, with the same mechanism: the `DISAGREE` report never
NAMED its state. It printed "the pinned sha appears 1 time(s) in charly.yml; expected at least 2"
and nothing else, so the table's State column names a state the report cannot put into words, and
a reader who greps the report for that name finds nothing. The other three reports name
themselves.
